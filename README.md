# Null32 Consulting Portfolio

Static single-page portfolio site for Null32 Consulting (Jason Clark) — "Websites & Custom Software". The page uses a full-screen ambient video background and a dark serif/sans design.

## Features

- Single-page marketing site with hero video background, fixed header, and section navigation (all inline HTML/CSS/JS in `index.html`).
- `index2.html` is a byte-identical copy of `index.html`.
- `CNAME` maps the site to the custom domain **meshpointsystems.com**.

## Tech stack

Plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Getting started

Open `index.html` in a browser, or serve the directory with any static server. The site is configured for GitHub Pages via the `CNAME` file.

## Project structure

```
.
├── index.html     # the site (all markup, styles, and script inline)
├── index2.html    # identical duplicate of index.html
├── ambient.mp4    # hero background video
└── CNAME          # custom domain: meshpointsystems.com
```
